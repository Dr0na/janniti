# Accessible Public Legal Communication

For every major law, create a public pack alongside the technical draft: plain-language summary, purpose and non-purpose, rights/equality impact, power map, consultation questions, implementation timeline, and remedies.

Provide relevant Indian-language translations, screen-reader HTML, easy-read version, captioned/sign-language media where appropriate, printable/offline distribution, low-data access, and local assistance. Test comprehension with affected users; do not call a translation or accessibility feature adequate without user validation.

Never simplify away legal limits, dissenting views, risks, or available remedies.
