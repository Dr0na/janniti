# Democratic Impact and Implementation Monitors

Create one dated JSON plan per consequential law or institutional framework, for example `monitoring/public-health-emergency-2026-07-26.json`, using `templates/democratic-impact-monitor.example.json`.

The monitor must measure both delivery and abuse: outcomes, cost, access, equality, freedom, selective enforcement, complaints, audit, data quality, and corrective action. It must preserve privacy and remain independent from the body being assessed.
