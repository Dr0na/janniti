# Claim-Level Provenance Ledgers

Store one JSON ledger per consequential legal deliverable in this directory, for example `provenance/emergency-powers-review-2026-07-26.json`. Start from `templates/claim-provenance.example.json` and validate with `scripts/validate_claim_provenance.py`.

The ledger is an audit trail. It must make it possible for another reviewer to trace every material legal conclusion to the source, version, pinpoint, date, and limitation. It does not replace reading the source, checking subsequent history, or qualified legal judgment.
