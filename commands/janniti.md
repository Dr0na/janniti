# /janniti

JanNiti's primary user command and default entry point for every new request.

Read and execute `commands/refine-and-route.md` with the supplied request as its input. Preserve the original request, refine only clear language errors, resolve only relevant repository and source context, and dispatch to the appropriate workflow. Do not merely suggest a route.

`/refine-and-route` remains a backward-compatible alias for this command.
