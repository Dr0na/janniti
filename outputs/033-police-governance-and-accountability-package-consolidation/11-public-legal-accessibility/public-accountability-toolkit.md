# Public Accountability Toolkit

## Citizen complaint minimum fields

Date/time/place; involved office or officer if known; event description; immediate safety/medical need; evidence at risk; accessibility/language need; confidentiality request; preferred contact; representative; declaration that the account is made in good faith.

## Emergency-register minimum fields

Legal source; objective evidence; purpose; decision-maker; geographical/personal scope; start time; expiry; reviewer; renewal; affected safeguard; public summary; court order if confidentiality is claimed.

## Accountability-data minimum fields

Arrests; custody deaths/injuries; complaints; preservation notices; evidence outages; transfer/discipline outcomes; criminal referrals; decision delays; budget request/provision/shortfall; equality indicators; methodology; correction log; audit date.

## Implementation checklist

- Map local police Act, rules, Gazette and cases.
- Name separate complaint, investigation, prosecution, discipline, audit and court functions.
- Publish appointment, budget, data, emergency and conflict rules.
- Create offline, accessible, multilingual complaint routes and legal-aid access.
- Train staff; test evidence systems and data controls; publish baseline metrics.
- Run public consultation, independent review and anti-capture test suite before commencement.
