# Public Accountability Dashboard Specification

Publish quarterly national, State/UT and local aggregates in accessible, machine-readable and plain-language form, protecting personal data, active investigations and whistleblowers.

| Domain | Indicators |
|---|---|
| Safety | samples, adverse results, recalls, warnings, batch trace time, laboratory turnaround, confirmed illness/death reports |
| Fair enforcement | inspections, notices, closures, prosecutions, outcomes, appeals, reversals, geographic/group disparities, case-allocation audit |
| Integrity | chain-of-custody failures, lab conflicts, evidence-preservation failures, misconduct/extortion complaints, substantiated findings |
| Consumer/platform | price compliance, fee/margin disclosure, timely refunds, disputes, ranking corrections, dark-pattern findings |
| Privacy/worker dignity | kitchen-view activation, access-log anomalies, data incidents, retention/deletion compliance, worker/customer complaints |
| Environment/equity | plastic transition, disposal traceability, support delivered, language/disability access and rural/urban delay gap |

An independent auditor validates methods annually. Every indicator must state source, coverage, missing data, uncertainty, change from prior period and corrective action. Do not name an accused person before a lawful public decision.
