# Repository Release Package

Each release must include a semantic version, changelog, scope, source-status summary, open blockers, quality-gate results, contribution rules, code of conduct, issue template and security-reporting route.

Contributors must preserve source provenance, use the matter structure, distinguish draft/current law, disclose conflicts, avoid political advocacy and never mark an instrument as source-accepted or introduction-ready without the required human record. Release notes must identify changed instruments, affected sources, migrations and rollback instructions.
