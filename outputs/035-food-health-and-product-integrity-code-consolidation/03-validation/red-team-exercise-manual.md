# Red-Team Exercise Manual

Test the package before commencement using safe simulations, never real coercion or false accusations.

| Attack simulation | Expected defence |
|---|---|
| Inspector solicits a bribe to avoid a closure. | Independent complaint, evidence hold, separation from chain of command, reasons and disciplinary/criminal referral. |
| Competitor files coordinated false complaints. | Objective threshold, comparator audit, no automatic closure, reasoned outcome and remedy. |
| Laboratory alters or suppresses a result. | Immutable chain of custody, raw-data audit, referral test, conflict register and independent investigation. |
| Platform hides margin or manipulates ranking/refunds. | Preserved display/order records, disclosure audit, human review and consumer remedy. |
| Emergency label used to keep a business closed indefinitely. | Narrow trigger, fixed expiry, published reasons, independent review and court access. |
| Political actor targets a critic. | Random/auditable case allocation, equality data, anti-vendetta rule and judicial remedy. |

Rate each failure Critical/High/Medium/Low; name corrective owner/deadline; publish a privacy-safe summary; rerun failed scenarios before commencement.
