# Pilot Usability Test Plan

Recruit disabled people, low-literacy users, older people, small vendors, delivery workers, rural users and relevant language groups. Test notice comprehension, complaint submission, sample challenge, refund, closure appeal, recall warning, legal-aid referral and non-video access.

Measure task completion, time, error, comprehension, need for assistance, privacy concern and remedy access. Publish anonymised results, unresolved barriers, corrective owner and retest result. A material accessibility failure blocks production rollout of the affected process.
