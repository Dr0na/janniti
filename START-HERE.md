# JanNiti — Start Here

JanNiti is a public-law drafting, research, review and accountability framework. It does not provide binding legal advice or enact law. Every consequential claim must be verified against current primary sources and, where appropriate, reviewed by qualified local counsel.

## Begin with a request

Use `/janniti <your request>` in a supported agent harness. It preserves the request, chooses the narrowest workflow, uses primary sources first, and records work in a numbered `outputs/` matter folder.

## Non-negotiable release rule

Do not label a draft as enacted, source-accepted, legally conclusive or introduction-ready until its source, competence, rights, quality and human-approval gates have passed.
